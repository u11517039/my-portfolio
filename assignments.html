課程實作與作業細項 (活動 01～09)

點擊下方任一作業卡片，即可展開查看詳細的學習學習重點、HTML/CSS 標籤應用與繳交檔案規範。

活動 01：HTML 文字層級標記

HTML 基礎
▼

練習使用 HTML 語意化文字標籤建立良好的文件層級結構。

  • 使用 <h1>～<h3> 標題層級標籤
  • 運用 <b> 粗體與 <i> 斜體進行重點強調
  • 運用 <sub>（下標）與 <sup>（上標）標記特殊文字
繳交檔名：01-html-text-學號.html

活動 02：影音多媒體嵌入與圖片格式

多媒體應用
▼

整合多元媒體元素，並理解網頁圖檔格式的特性與選用時機。

  • 嵌入圖片 <img>（設定 alt 替代文字與 width 尺寸）
  • 比較照片 JPG、透明圖 PNG 及向量圖 SVG 的差異
  • 加入 <audio> 與 <video> 多媒體播放控制項 (controls)
繳交檔名：02-html-media-學號.zip（含媒體資料夾）

活動 03：結構化清單與表格設計

資料結構化
▼

將資料進行邏輯化呈現，打造易讀的無序/有序清單與表格結構。

  • 使用 <ul>（無序清單）與 <ol>（項目編號清單）
  • 建立 <table> 表格結構，包含 <caption> 標題說明
  • 運用 <tr>、<th>（表頭）與 <td>（資料格）呈現數據
繳交檔名：03-html-plan-學號.html

活動 04：互動表單元件實作

互動介面
▼

設計使用者輸入介面，學習各種常見的網頁表單控制項。

  • <input type="text"> 單行文字輸入框與按鈕
  • <select> / <option> 下拉選單設計
  • <input type="radio"> 單選群組與 checkbox 複選框
  • <textarea> 多行文字輸入區域
繳交檔名：04-html-form-學號.html

活動 05：CSS 視覺風格與盒子模型

CSS 風格
▼

調整網頁視覺色彩與 Box Model 間距參數。

  • 色彩設定（Hex 色碼如 #1b4332）與文字樣式
  • 控制 padding（內距）、margin（外距）與 border
  • 運用 border-radius 設定卡片與按鈕的圓角效果
繳交檔名：CSS-05-學號.zip（含修改說明.txt）

活動 06：Grid 整頁版型切換

網頁排版
▼

運用 CSS Grid 網格系統構建現代化頁面版型。

  • 單欄版型 A（簡潔集中）
  • 雙欄版型 B 與三欄版型 C（多欄位資訊對齊）
  • 側欄與主內容版型 D（經典網站版面構架）
繳交檔名：CSS-06-學號.zip（含修改說明.txt）

活動 07：Flexbox 卡片排列與圖片裁切

卡片排版
▼

使用 Flexbox 實現對齊卡片與圖片比例控制。

  • align-items: stretch 與 gap 間距調整
  • 運用 object-fit: cover / contain 避免圖片失真拉伸
  • 彈性長度的圖文混合卡片佈局
繳交檔名：CSS-07-學號.zip（含 images 資料夾）

活動 08：RWD 響應式網頁設計

跨裝置適應
▼

針對行動裝置與桌面螢幕進行彈性調整。

  • 使用 @media 媒體查詢（如寬度 600px 以下切換為單欄）
  • 設定流體圖片與寬度（max-width: 100%）
  • 無障礙導覽列在手機版上的直排調整
繳交檔名：CSS-08-學號.zip（含修改說明.txt）

活動 09：WAVE 無障礙檢測與優化

無障礙網檢
▼

優化網站可存取性，確保所有人皆能順暢閱讀與操作。

  • 使用 WAVE 工具檢測色彩對比度（目標至少 4.5:1）
  • 補齊表單 <label> 標籤的 `for` 屬性關聯
  • 設定鍵盤游標焦點樣式 (:focus-visible)
繳交檔名：CSS-09-學號.zip（含修改說明.txt）
