數位科技概論作品集

第二週學習紀錄．GitHub 檔案取回與更新、HTML 活動 01–04、CSS 活動 05–09

這一週先從自己上週上傳到 GitHub 的作品集取回檔案，練習修改 HTML 內容與結構，再進一步用 CSS 調整外觀與版面。下面每個項目點一下標題就能展開看細項，內容是我對本週講義的學習整理。

一、GitHub 檔案取回與更新

從自己的儲存庫下載檔案、修改後再上傳

用 Download ZIP 把上週的作品集下載下來解壓縮，分別用瀏覽器和文字編輯器開啟同一份 index.html，一邊看畫面一邊改內容。

修改完成後，回到原本的儲存庫，用 Upload files 把 index.html（以及新增的圖片、CSS 等資源）依照原本的路徑重新上傳，填寫修改說明並完成 Commit，最後回到公開網址確認畫面已經更新。

重點提醒：上傳時不要把外層資料夾一起拖進去，也不要上傳 ZIP 壓縮檔本身，否則首頁會找不到。

小作業：把一段沒有標籤的科學活動文字，依照角色分派成正確的標題層級與段落，並標記需要粗體、斜體、上下標的地方。

三、CSS 活動 05–09

活動 05｜同一份內容，換一種風格

用色彩實驗室練習挑選色碼，並修改標題顏色、重點文字顏色、卡片的留白（padding／margin）、圓角與內文字體大小、行高，觀察同一份 HTML 在不同 CSS 下的視覺差異。

活動 06｜我的網站適合哪種版型

比較單欄、兩欄、三欄、側欄＋主內容四種版型的區域關係與適合用途，並練習調整導覽欄寬度，理解 fr 單位如何分配剩餘空間。

活動 07｜把內容排得整齊

用 display: flex 讓多張作品卡片間距一致、同排等高，並比較 object-fit: cover 與 contain 兩種圖片裁切方式的差異。

活動 08｜從電腦版變成手機版

把固定寬度改成 width: 100%; max-width: ...，並用 @media (max-width: 600px) 讓卡片在小螢幕變成單欄排列，確認寬螢幕與窄螢幕畫面都正常、沒有橫向捲動。

活動 09｜先機檢，再修正無障礙問題

使用 WAVE 工具檢查網頁，找出文字對比不足與表單缺少標籤兩個問題並手動修正，再檢查鍵盤 Tab 焦點是否清楚可見、狀態是否不只靠顏色傳達，以及放大 200% 後版面是否仍可正常閱讀。

學習紀錄

本週練習只使用 HTML 與 CSS，沒有加入 JavaScript 或套件。五個 CSS 活動都完成觀察後，我會從中選一個案例做進一步修改，作為這階段的統一作業。
